## 2. Dependency Audit Results

### 2.1 Cargo Audit (`contracts/`)
Audit performed against RustSec Advisory Database:
- **`crypto-bigint 0.5.5` (RUSTSEC-2026-0387)**: Timing variability in operations intended to be constant-time.
  - *Evaluation:* Transitive dependency of `soroban-env-host 21.2.1` via `p256`. Soroban smart contracts run inside the Soroban WASM guest sandbox and do not execute variable-time host cryptographic operations directly in contract guest code. The Soroban SDK pinned version cannot be upgraded independently without a breaking protocol change.
  - *Action:* Documented and added to `contracts/audit.toml` ignore list.
- **`paste 1.0.15` (RUSTSEC-2024-0436)**: `paste` crate is unmaintained.
  - *Evaluation:* Widely used declarative macro utility used by `soroban-sdk`. Contains no unsafe code or security vulnerabilities.
  - *Action:* Documented and ignored.

### 2.2 Pnpm Audit
Audit performed across root monorepo:
- **`fast-jwt` / `@fastify/jwt 8.0.1`**: Upstream advisory for fast-jwt cache key handling.
  - *Mitigation:* API service does not use custom `cacheKeyBuilder` or multi-tenant RSA public key caching; all tokens are verified with HMAC-SHA256 using `JWT_SECRET`. Strict JWT verification tests implemented in `api.test.ts`.
- **`next` (v14.2.35 in apps)**: Minor advisory regarding middleware cache poisoning.
  - *Mitigation:* PWA and dashboard applications do not use custom proxy rewrite middleware or cache-busting headers subject to cache poisoning.
- **`toml` (v3.0.0 via `@stellar/stellar-sdk`)**: Unbounded integer parsing DoS.
  - *Mitigation:* Not exposed to untrusted external input; Stellar SDK configuration uses static TOML files only.
